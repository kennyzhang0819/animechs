# Mindustry sprites

`sprites/` is a full mirror of [Mindustry](https://github.com/Anuken/Mindustry)'s
sprite assets (`core/assets-raw/sprites/`, ~2,200 files), by Anuken and
contributors, licensed under **GPL-3.0**. They are used here as placeholder art
in a personal prototype; the folder layout is Mindustry's own (blocks/, units/,
effects/, items/, ui/, ...).

The game's atlas (`game/atlas.ts`) composites a small subset at load time —
swap any path there to restyle the game without touching the render pipeline.

If this project is ever distributed, GPL-3.0 terms apply to these assets;
replace them with original art for a commercial release.
